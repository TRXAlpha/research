# Literature workflow

`references.bib` is an initial bibliography, not a completed systematic review.

For every candidate work, record:

- publication status: peer reviewed, workshop, preprint, code, or commentary;
- affect source: assigned, inferred from text, inferred from activations, or endogenous;
- state location: prompt, external symbolic state, hidden activations, weights, or memory;
- temporal persistence;
- cognition-to-affect feedback;
- intervention and measurement independence;
- cognitive domains evaluated;
- matched baselines and ablations;
- released code/data;
- exact overlap with the proposed contribution.
